# SilentMoon ![Header Image](https://github.com/realist-pessimist/FRP-SilentMoon/blob/main/assets/457651592-e8ced29d-450b-4fe1-ab3e-d284f65d54a8.svg)   
*Приложение для медитации на Kotlin с функциональным подходом*

## 📖 О проекте
**SilentMoon** — Демонстрационная версия минималистичного приложения для медитации, разработанное в рамках цикла статей о функциональном программировании на Kotlin. Проект демонстрирует практическое применение:

- Теории категорий (порядки, функторы, произведения, функторы)
- Композиция функций
- Каррирования и частичного применения
- Closure
- Мемоизация
- Моноид
